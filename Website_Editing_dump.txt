Website Product Flow & Data Structure Explanation. 
The website product section will be controlled using three structured sheets: 
Sheet 1 – Product Listing & country wise sheet 
Sheet 2 – Filter Mapping and Short product description 
Sheet 3 –Technical Data sheet 
Each sheet has a specific purpose and must be integrated properly into the website backend. 
Overview: 
The navigation interface for the Laboratory Weighing section on the website is designed to be interactive and user-friendly. The user will experience a dynamic dropdown menu with clear hover effects, making it easier to explore product categories and subcategories. 1. Main Category: 
Name: Laboratory Weighing 
Location: Displayed at the top-level navigation. 
Appearance: 
Each category is represented as a rectangular block with a label (e.g., Laboratory Weighing)  
The background of the category block will be in a  neutral color  
The colour of the text will be Black and turquoise colour
2. Hover Effect: 
Action: When the user hovers their cursor over a category block (e.g., Laboratory Weighing), the color of the block will change to highlight that the user is interacting with that category. [the drop down will work on both effect, pointing the cursor (navigation)and click both]
Purpose: This effect serves as an indication of interactivity, letting the user know that the category is clickable and will reveal more options. 
When the user hovers the cursor over a category block (e.g., Laboratory Weighing), the category block background/highlight will change to turquoise colour to indicate interaction.
When the user clicks a category or keeps the cursor positioned over it (active hover state), the selected category will remain highlighted in turquoise colour to show the current focus/selection.
3. Subcategory Dropdown: 
Action: Once the user hovers over a category (e.g., Laboratory Weighing), additional options (subcategories) will appear next to  the category block. 
Subcategories:  
Laboratory Balances 
Microbalances 
Analytical Balances 
Precision Balances and Scales 
Density Scales 
Moisture Analyzers 
Test Weights 
Accessories for Laboratory weighing 
 
These will be shown in a  side panel ,drop-down format, presenting further specific categories under the main product category. 
 
4. Subcategory Interaction: 
Appearance: The subcategories will be displayed in a vertical list that appears when hovering over the main category block. 
Hover Effect for Subcategories: As the user hovers over each subcategory, the background color will slightly change to indicate which subcategory is currently selected. 
Behavior: The subcategory panel should disappear when the user moves their cursor away from the category block and its subcategories. 
 
5. Visual Styling and Aesthetic: 
Color Scheme: 
The main categories will use a light background color (e.g., light gray ), which changes to a highlighted color  (green) when hovered. 
The subcategory dropdown will be presented with a clean, white background, and the text will match the website’s font style. 
Spacing & Alignment: 
There will be adequate spacing between the main categories to make the navigation clean and easy to read. 
The subcategory dropdowns should align perfectly with their parent categories, ensuring a seamless and organized structure. 
Responsiveness: The design should be responsive, ensuring that it works well on both desktop and mobile devices.

All category options are properly aligned in a vertical list with checkboxes, enabling users to select one or multiple categories to filter the results displayed on the page.   Category Filter Functionality  Next to the Category title, there is an arrow icon that works as a dropdown control. When the user clicks on this arrow, the complete list of available categories will expand or collapse, allowing the user to easily view and select different product categories. 
This helps users quickly filter products and navigate through the available laboratory balance categories. 
 When a user selects Microbalances from the Category filter, only the products that belong to the Microbalance category will be displayed on the product list. The system will also show the total number of products available under this category (for example, 18 Results). 
Users can select one or more categories from the Category filter. If a single category such as Microbalances is selected, only products under the Microbalance category will be displayed along with the total number of results. 
If multiple categories are selected (for example, Microbalances and Analytical Balances), the system will display all products that belong to both selected categories. The results count will update automatically to show the total number of products matching the selected filters. Series Filter Behavior with Category Selection 
When a Category such as Microbalances is selected, the product list will update to display only the products that belong to the Microbalance category. 
If the user then expands the Series dropdown, only the series that belong to the selected category (Microbalances) will be available for selection. Each series will also display the number of products available in that series (for example, AXR (9), CM (9)). 
Series that do not contain any products under the selected category will automatically become unavailable or disabled (shown as 0) and cannot be selected. 
This ensures that users only see relevant filter options based on the selected category, making the filtering process easier and more accurate.   Type Filter Functionality
Under the Microbalances category, there are four available product types:
Microbalance – 7 products
Filter Microbalance – 7 products
Pipettes Microbalance – 2 products
Stent Microbalance – 1 product
Only the product types that belong to the selected category will remain active and selectable. The remaining product types will appear blurred and locked, indicating that they are not applicable to the current category selection.
For example, when Microbalances is selected, only the above four related types will be available. If the user selects another category, the available types will automatically change according to the products under that selected category.
Weighing Capacity Filter – Microbalance Category
The Weighing Capacity filter will display all available capacity options. However, only the capacities applicable to the selected product category will remain active.
For the Microbalance category, the available weighing range is 2 g to 11 g:
2 g (5) – 5 products available 
5 g (3) – 3 products available 
6 g (5) – 5 products available 
11 g (5) – 5 products available 
These four options will be selectable. All other weighing capacities will appear greyed out or disabled, because no Microbalance products are available in those capacity ranges.
The number shown in brackets indicates how many products fall under that particular weighing capacity. 
Capacity ranges that do not belong to the selected category (Microbalances) will be automatically disabled / blocked, and the user will not be able to select them. 
This ensures the user can select only valid capacity ranges with available products, and the count helps the user understand how many products match that filter.

Comparison Feature Overview
1. Step 1: Select Products to Compare
When a user clicks on the “Compare” checkbox next to a product, the product comparison feature will be activated.A “Compare” button will appear at the bottom of the product listing page, indicating that one or more products have been selected.The user can continue selecting similar products and add a maximum of 10 products to the comparison list.
The interface should also display the number of selected products, for example:
Compare Products (2/10)
If the user tries to select more than 10 products, the system should prevent the selection and display the following message:
Only products from the same or similar product category can be compared. If the user attempts to select an unrelated product, the system will not allow the selection and will display an appropriate message.
For example, CY 224C and CPR 02 belong to different product categories and therefore cannot be compared.
Suggested message:
“The selected product belongs to a different category and cannot be added to this comparison. Please select a similar product.”
2. Step 2: Activate the Comparison View
After selecting at least two similar products, the user can click on the “Compare” button.
A comparison interface will open, displaying all selected products side-by-side.
The comparison interface can display a minimum of 2 products and a maximum of 10 products at a time.
Each selected product will be shown with its key features and specifications for easy comparison.
3. Step 3: Side-by-Side Product Comparison
All selected products will be displayed side-by-side in the comparison interface.
The comparison view will show the following details for each product:
If many products are selected, the comparison table should support horizontal scrolling so that users can easily review all selected products.
Users should also be able to remove any product from the comparison interface without returning to the product listing page.
4. Print and Download Comparison Sheet
A “Print” button will be available in the comparison interface, allowing users to print the complete product comparison sheet.
The selected product comparison can also be downloaded or shared in the following formats:
PDF
The exported PDF should include the product names, images, key features, and complete technical specifications of all selected products.
The comparison sheet should support a maximum of 10 products.
